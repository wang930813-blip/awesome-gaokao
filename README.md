## 🧰 备考工具 · Interactive Study Tools

可以直接在浏览器里用的交互工具，无需安装，手机可用。

- [gaokao-tools](https://github.com/daligao/gaokao-tools) — 免费离线备考工具箱，22个工具覆盖6科：英语词汇/语法/写作/完形/阅读真题，数学公式闪卡78张，物理公式闯关60题，生物真题380套，化学/物理/语文考点速查手册。手机可用，无需登录。· [在线试用](https://daligao.github.io/gaokao-tools/)
- [EXAM-MASTER](https://github.com/CiE-XinYuChen/EXAM-MASTER) ⭐182 — 基于 Flask 的在线刷题系统，支持题库管理、随机出题、模拟考试、收藏标记、统计分析，可自托管部署。
- [gaokao_exam](https://github.com/shaodongtang/gaokao_exam) ⭐86 — 高考试卷 LaTeX 模板集合，可本地排版生成标准格式试卷，适合老师自制模拟卷。
- [gaokao_tutor](https://github.com/chipfighter/gaokao_tutor) ⭐60 — 基于 LangGraph 的高考辅导 Agent，集成情感识别、RAG 试卷检索与个性化学习规划。
- [education-skills](https://github.com/flysheep-ai/education-skills) ⭐80 — Claude Code 教育类 Skills 集合，含各科辅导和学习支持工具，可接入 AI 对话式辅导。

## 📐 数学 · Math

- [gaokaomath](https://github.com/deekur/gaokaomath) ⭐1416 — 历年高考数学真题完整收录（1952–2026），按年份整理，GitHub 上最全的高考数学真题库。
- [project-asteria](https://github.com/woct0rdho/project-asteria) ⭐45 — 面向竞赛和拔高方向的进阶数学入门，涵盖高等数学与理论物理基础，适合尖子生冲刺。

## ⚡ 物理 · Physics

- [gaokaophysics](https://github.com/deekur/gaokaophysics) ⭐91 — 历年高考物理真题收录，与 gaokaomath 同一作者，按年份整理，包含全国卷及各省卷。

## 📖 英语 · English

- [awesome-gaokao-english](https://github.com/daligao/awesome-gaokao-english) — 高考英语资源精选列表：词汇、语法、写作、完形填空、阅读，收录工具、学习平台、GitHub 项目。
- [GAOKAO-Bench](https://github.com/OpenLMLab/GAOKAO-Bench) ⭐788 — 含英语科目的高考 AI 评测框架，2811道真题（2010–2022），结构化数据可用于题型分析。
- [AI-Gaokao](https://github.com/ExpressAI/AI-Gaokao) ⭐109 — Gaokao English AI benchmark，含听力、完形、阅读、填空四类题型的标准化数据集。

## 🧬 生物 · Biology

- [gaokao-tools/shengwu](https://github.com/daligao/gaokao-tools) — 内含生物选择题真题380套（全国卷+各省卷）、生物填空对对碰、生物考点速查手册（30+章节130+考点），离线可用。
- [GAOKAO-MM](https://github.com/OpenMOSS/GAOKAO-MM) ⭐82 — ACL 2024，含生物图表题的多模态高考基准，覆盖含图选择题，可用于了解图表题考点分布。

## 📚 综合资料 · Study Materials

- [Gaokao-Study-Materials](https://github.com/HK-SHAO/Gaokao-Study-Materials) ⭐39 — 高中各科学习资料和高考备考资料汇总，包含英语真题 PDF、各科笔记，学生自发整理。
- [Laosheng.top](https://github.com/DiamonWoo/Laosheng.top) ⭐145 — 汇总教育、新闻、工具类资源，含高考相关资源入口，节约搜寻时间。

## 🎓 志愿填报 · College Application

- [gkvr_system](https://github.com/electronic-pig/gkvr_system_backend) ⭐112 — 高考志愿推荐系统，前后端完整开源，基于往年录取数据智能推荐院校专业。
- [Zhangxuefeng-AI-gaokao](https://github.com/Pilot1799/Zhangxuefeng-AI-gaokao) ⭐88 — 基于本地知识库 + 向量引擎 + 大模型的高考志愿咨询系统，开源可自托管。
- [gaokao-advisor-skill](https://github.com/ZeoxCode/gaokao-advisor-skill) ⭐68 — 站在考生和家长一边的高考志愿决策 Agent，可接入 Claude Code 使用。
- [gaokao-mentor-wisdom](https://github.com/dongsheng123132/gaokao-mentor-wisdom) ⭐62 — 张雪峰志愿填报语录结构化 JSON 数据集，含专业选择、院校推荐、就业前景分析。
- [gaokao](https://github.com/firmianay/gaokao) ⭐46 — 高考志愿参考系统，整理各省历年录取分数线数据。

## 🔬 AI 基准数据 · Benchmarks

> 以高考题为测试集评估 AI 能力的数据集，也可用于了解各科考点分布和出题规律。

- [GAOKAO-Bench](https://github.com/OpenLMLab/GAOKAO-Bench) ⭐788 — 最广泛使用的高考 AI 评测框架，语文/数学/英语/理综/文综，2811题（2010–2022）。
- [GAOKAO-Eval](https://github.com/open-compass/GAOKAO-Eval) ⭐125 — OpenCompass 出品，支持主流大模型自动评测，含多科目分类统计。
- [GAOKAO-MM](https://github.com/OpenMOSS/GAOKAO-MM) ⭐82 — ACL 2024，多模态高考基准，含物理、化学、生物图表类选择题。
- [AI-Gaokao](https://github.com/ExpressAI/AI-Gaokao) ⭐109 — 英语专项 benchmark，听力/完形/阅读/填空四类结构化数据。
- [AGIEval](https://github.com/ruixiangcui/AGIEval) — 含 gaokao-english 子集，广泛用于测试 GPT-4 等模型的考试水平。
- [GAOKAO-Bench-Updates](https://github.com/OpenLMLab/GAOKAO-Bench-Updates) ⭐48 — GAOKAO-Bench 持续更新版，补充最新年份真题。
